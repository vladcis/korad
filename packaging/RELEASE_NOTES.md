KORAD KA3005PS / KA3005P control software (also Tenma 72-2535, RND 320-KA3005P, Velleman LABPS3005D).

## 🖥️ Native desktop app – own window (recommended)

| System | Download |
|---|---|
| Windows 10/11 (64-bit) | `korad-windows-x64.exe` |
| macOS (Apple Silicon) | `korad-macos-arm64.zip` |
| Debian 12+ / Ubuntu 22.04+ / Raspberry Pi OS | `korad_*_all.deb` → `sudo apt install ./korad_*_all.deb` |
| Linux, any distro (x86-64) | `korad-linux-x86_64.AppImage` → `chmod +x` and run (self-contained) |

## 🌐 Web app – UI in your browser

| System | Download |
|---|---|
| Linux (x86-64) | `korad-linux-x86_64-web` → `chmod +x` and run; opens your default browser. Also for headless use: `--server --port 8585` |
| Any OS | source code: `python3 app.py` → http://127.0.0.1:8585 |

Setup notes for each system: [README](https://github.com/vladcis/korad#1-download-no-python-needed)
